# Website cá nhân PLC Engineer

Mở `index.html` bằng trình duyệt để xem website.

## Đưa lên GitHub Pages
1. Tạo tài khoản GitHub.
2. Tạo repository mới, ví dụ `plc-engineer`.
3. Upload `index.html`, `style.css`, `script.js`.
4. Vào Settings → Pages → Deploy from branch → chọn `main` / root.
5. GitHub sẽ cấp địa chỉ dạng `https://tenban.github.io/plc-engineer/`.

Có thể thay tên, email, Facebook, TikTok và nội dung trong `index.html`.
